# 真人旁白稿

## 35 秒版本

这是 Polymarket EV Desk，一个用 Vibe Coding 完成的 Flutter Web PWA。

它面向预测市场研究，可以准实时同步 Polymarket 行情，每 60 秒刷新价格，并在本地重算 EV Gap 和 Kelly 仓位。

中文模式会本地化常见市场标题，同时保留英文原题，方便说明真实数据来源。

项目只做分析，不保存私钥，也不自动下单。

目前已经提供 GitHub 仓库、线上 Demo、Release 体验包和需求分析文档，展示从需求拆解到上线演示的完整闭环。

## 录音建议

- 用 iPhone 语音备忘录录制即可。
- 语速自然，不要刻意播音腔。
- 录完导出 `m4a` 或 `mp3`。
- 背景尽量安静，离手机 20 到 30 厘米。
- 发给我后，我可以做降噪、音量标准化并合成到视频里。
